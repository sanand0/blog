This week, I learned:

- LLMs are so good that they can simulate Doom in real time. [gamengen](https://gamengen.github.io/)
- [Val.town's code generation system prompt](https://gist.github.com/simonw/d8cc934ad76b3bba82127937d45dc719) uses <https://maxm-imggenurl.web.val.run/the-description-of-your-image> to dynamically generate images
- Practice for each thought: "What would make me change my mind? How likely is that?"
- [Cursor uses speculative edits](https://www.cursor.com/blog/instant-apply) and a variety of other techniques to speed up code editing.
- [ChatGPT does a better job at cartoon generation than even Flux.1](https://www.s-anand.net/blog/image-generation-gets-better-at-comics/)
