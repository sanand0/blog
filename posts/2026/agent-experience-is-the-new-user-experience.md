Agents are increasingly the consumers of things that used to be made for humans: <!-- https://chatgpt.com/c/6a6c7803-d62c-83ec-8144-15cf74b3219c -->

- _Docs_ are increasingly for agents to _read_. E.g. [`llms.txt`](https://llmstxt.org/)
- _Code_ is increasingly for agents to _edit_. E.g. [`AGENTS.md`](https://agents.md/)
- _Tests_ are increasingly for agents to _satisfy_. E.g. [SWE-bench](https://www.swebench.com/), [GitHub repository](https://github.com/SWE-bench/SWE-bench)
- _Software_ is increasingly for agents to _operate_. E.g. `--json`, `--schema`, [`--dry-run`](https://clispec.dev/), [CLI-Anything](https://github.com/HKUDS/CLI-Anything), [AXI](https://axi.md/)
- _Websites_ are increasingly for agents to _invoke_. E.g. [WebMCP](https://developer.chrome.com/docs/ai/webmcp)
- _Capabilities_ are increasingly for agents to _discover_. E.g. [MCP tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools), [MCP Registry](https://registry.modelcontextprotocol.io/)
- _Procedures_ are increasingly for agents to _follow_. E.g. [`SKILL.md`](https://agentskills.io/specification), [Agent Skills](https://github.com/agentskills/agentskills)
- _Products_ are increasingly for agents to _choose_. E.g. [Universal Commerce Protocol](https://ucp.dev/)
- _Money_ is increasingly for agents to _spend_. E.g. [Agent Payments Protocol](https://github.com/google-agentic-commerce/AP2)
- _Identity_ is increasingly for agents to _prove_. E.g. [Visa Trusted Agent Protocol](https://developer.visa.com/capabilities/trusted-agent-protocol/trusted-agent-protocol-specifications/)
- _Agents_ are increasingly for agents to _delegate_ to. E.g. [A2A Agent Cards and Tasks](https://a2a-protocol.org/latest/specification/)
- _Humans_ are increasingly for agents to _escalate_ to. E.g. [MCP Elicitation](https://modelcontextprotocol.io/specification/2025-11-25/client/elicitation)

[Agent Experience](https://www.google.com/search?q=agent+experience) or AX is the new UX.
