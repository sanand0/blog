At work, we have to change passwords every 2 months. The password rules are stringent and it typically takes me 10 minutes to find one that works.

Here are the rules:

1. The password being setup must have a minimum length of 12
2. Minimum number of special character to be included in the new password is 1
3. Must contain at least 1 upper case character(s)
4. Must contain at least 1 lower case character(s)
5. Minimum number of numeric characters to be included in the new password is 1
6. The construction of the password cannot contain Palindromes. The system has been configured to prevent such passwords
7. The system is configured to not allow the **last 24 passwords**. A password once setup is **valid for 60 days** after which it expires. A password once setup must be used for a minimum of 2 days
8. A list of **common words** has been restricted to be used as passwords. This list is available on the password change page of the self service portal
9. The construction of the password must not contain **5 consecutive characters** from the Username or previously used passwords

This is so complex. Rules #5 and #8 makes it especially tough. I tried all my standard password strategies:

- Rotating passwords. But I can't rotate passwords for about _4 years_ (24 passwords x 2 months each)!
- Tweaking old passwords. But you can't use 5 consecutive characters from old passwords!
- Using [passphrases](https://xkcd.com/936/). But common words are banned!

So I decided to swear at it in Tamil.

But it fought back!

- [`PanjaParadesi`](https://www.google.com/search?q=What+does+Panja+Paradesi+mean) was disallowed because `parade` is not allowed
- [`PakkiPannada`](https://www.google.com/search?q=What+does+Pakki+Pannada+mean) was disallowed because `panna` is not allowed
- [`MollaMaari`](https://www.google.com/search?q=What+does+Molla+Maari+mean) was disallowed because `llama` is not allowed

[Namit](https://www.linkedin.com/in/namit-sureka-43ab89/) finally suggested a standardized password strategy that works for me, e.g. use the month you change the password, with a (max) 4-letter prefix or suffix, like `GramNov2026$`.

There you go. I now have a safe password strategy that nobody will guess!
